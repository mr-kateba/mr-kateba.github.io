# الأناشيد

ضع ملفات MP3 في هذا المجلد، ثم أضفها إلى `list.json` بالترتيب الذي تريده:

```json
{
  "avatar": "assets/me.jpg",
  "background": "assets/bg.jpg",
  "tracks": [
    { "title": "اسم النشيد", "artist": "المنشد", "file": "nasheeds/1.mp3" }
  ]
}
```

- `avatar`: الصورة الرئيسية (اتركها فارغة لشعار بلازما).
- `background`: صورة الخلفية (اختيارية).
- `cover` داخل أي نشيد: صورة خاصة به (اختيارية).

حجم الملف الواحد على GitHub أقل من 100 ميجا.
